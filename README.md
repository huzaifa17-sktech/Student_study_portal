# 🎓 Student Study Portal

A feature-rich Django-based web application designed for students to manage their academic tasks efficiently. This portal provides a personal dashboard to manage notes, homework, and to-do lists, along with integrated study tools like YouTube search, book search, dictionary, Wikipedia, and unit conversion.

---

## 🚀 Features

### ✅ User Authentication
- User Registration & Login
- Data access is personalized per user
- Forgot Password functionality (email-based password reset)
- Password reset via link sent to registered email
- Personalized dashboard for each user


### 📝 Notes Section
- Add, view, and delete notes
- View full note detail

### 📚 Homework Tracker
- Add subject-wise homework with due dates
- Mark homework as completed/incomplete
- Delete homework
- Track pending homework in user profile

### 📌 To-Do List
- Add daily to-dos
- Mark them finished or unfinished
- Delete tasks
- Check status in profile page

### 📺 YouTube Video Search
- Search educational content via YouTube
- View title, channel, duration, views, published time, and thumbnails

### 📖 Book Search (Google Books API)
- Search books by topic or keyword
- View title, subtitle, description, page count, categories, rating, and preview link

### 📘 Dictionary Lookup (Free Dictionary API)
- Search English words
- View phonetics, pronunciation audio, definition, example, and synonyms

### 🌐 Wikipedia Integration
- Search topics
- View Wikipedia title, summary, and article link

### 📏 Unit Conversion
- Convert Length: Yard ↔ Foot
- Convert Mass: Pound ↔ Kilogram

### 👤 User Profile
- View all pending homework and todos in one place

---

## 🛠️ Tech Stack

- **Framework:** Django
- **Database:** SQLite (default)
- **Frontend:** Django Templates + HTML/CSS
- **Authentication:** Django Auth System
- **APIs Used:**
  - YouTube Search Python
  - Google Books API
  - DictionaryAPI
  - Wikipedia
